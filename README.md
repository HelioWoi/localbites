# MenuLove (formerly LocalBites)

Originally launched as LocalBites, this project has evolved into MenuLove — a video-first menu platform built to help restaurants showcase dishes through short-form video, QR access, and a more conversion-focused customer experience.

## Live Website
https://menulove.com.au

## Project Evolution
LocalBites was the original concept and codebase. As the product direction became clearer, the platform was repositioned and migrated under the MenuLove brand.
