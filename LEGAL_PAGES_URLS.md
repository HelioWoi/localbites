# Legal Pages - Direct Access URLs

## 🔗 URLs de Acesso Direto

Agora você pode acessar as páginas legais diretamente através de URLs simples:

---

## 📄 **Privacy Policy (Política de Privacidade)**

**URL Curta:**
```
https://www.menulove.com.au/policy
```

**URL Completa:**
```
https://www.menulove.com.au/legal/privacy-policy.html
```

**Localhost:**
```
http://localhost:3000/policy
```

---

## 📋 **Terms of Service (Termos de Serviço)**

**URL Curta:**
```
https://www.menulove.com.au/terms
```

**URL Completa:**
```
https://www.menulove.com.au/legal/terms-of-service.html
```

**Localhost:**
```
http://localhost:3000/terms
```

---

## 🛡️ **Content Moderation Policy (Política de Moderação)**

```
https://www.menulove.com.au/content-moderation
```

**URL Completa:**
```
https://www.menulove.com.au/legal/content-moderation.html

```

---

## 🎯 **Como Funciona:**

1. **Rotas Curtas:** `/policy`, `/terms`, `/content-moderation`
2. **Redirecionamento Automático:** Para os arquivos HTML estáticos em `/legal/`
3. **SEO Friendly:** URLs limpas e fáceis de lembrar

---

## 📱 **Uso no App:**

### **No Footer:**
```typescript
<a href="/policy">Privacy Policy</a>
<a href="/terms">Terms of Service</a>
<a href="/content-moderation">Content Moderation</a>
```

### **No Partner Signup:**
```typescript
By signing up, you agree to our 
<a href="/terms" target="_blank">Terms of Service</a> 
and <a href="/policy" target="_blank">Privacy Policy</a>
```

### **Em Emails:**
```
Privacy Policy: https://www.menulove.com.au/policy
Terms of Service: https://www.menulove.com.au/terms
```
